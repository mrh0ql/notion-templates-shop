# Notion Templates Shop

Three ready-to-sell Notion templates plus a guide for listing them on Gumroad for passive income.

## Templates
| Template | File | Price |
|---|---|---|
| Freelancer Dashboard | `templates/freelancer-dashboard.md` | $19 |
| Income Tracker | `templates/income-tracker.md` | $9 |
| Project Planner | `templates/project-planner.md` | $15 |

Each file describes the exact structure to build in Notion (databases, properties, views) so you can recreate the template and duplicate it for buyers.

## How to sell
1. Build each template in Notion from its spec file.
2. Make the page shareable as "Duplicate" (template link).
3. List it on Gumroad following `gumroad-listing-guide.md`.
4. Deliver the duplicate link automatically on purchase.
